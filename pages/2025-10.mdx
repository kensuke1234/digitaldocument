## 文京区

---

文京区のespoir 西片
文京区のespoir 西片に住んで。まるで、宮前平の時のような感覚。都内だから比較的にどこにでもすぐ行ける。上野、池袋、後楽園、神保町、東京駅周辺などに散歩可能。屋上が優秀で、今まで屋上ランキングでは、横浜、下北、西片かな。部屋の使いやすさは、下北より使いやすい。どこと比べるとわかりやすいか。新宿、下北、宮前平かな。鎌倉の家が大きく、印象が強いのでそのあとは印象が薄れるだろうなと予想していた。確かにそうなる。
新宿は建物自体が高級感がある建物だったので部屋もホテルのようで。どっちかというと下北は部屋が狭すぎ。だが、外が面白いので1年いた。東京都内では、9.5ぐらいの値段で新宿、下北と住んでみたが、それと比べると外の面白さがあまりない。というかないわけじゃなくて、渋谷や新宿、下北、三茶という活気がある街ではないからじゃないか。ここらは上野、本郷、神保町、池袋とかに出やすい。逆に、部屋は使いやすい、風呂や屋上、キッチンなどはほぼ一人として使用可能だし、いる人も穏やか。
家に不満はないが、ただ、外の面白さというか街の良さが伝わってこないから。屋上だって、1,2を争うよさ。都内で屋上を見たのは下北のみ。8.5の宮前平と比べて、まず東京だし。

## 2年前の拝島で撮影した映像

---


2年前に拝島で映像を撮り溜めていて、それを早朝からじっくり鑑賞。2年前だからまだ鎌倉に行く前で、確かに3月ごろに2年前の心理的にポジティブだった海全盛時代にフォールバックしようと考えていて、鎌倉に引っ越した。実際は、住んだら住んだでそんなに海に入らず。2023年3月ぐらいで拝島でもいいけど、海行ったらどうなるだろーと、そしてうまい具合に鎌倉ハウスができた。ハウス閉鎖。鎌倉では、落ち着いた生活で、単位取得して、横浜もよく通った。1年の間、神社が多い街で、海にも近く夏は特別に良かった。
デザインとAIITが1年目とかで、造形基礎、デザイン研究3などを受けたあたり。デザインシンキング後とかで、色々考えていた。それまでの自分の考えなど、政治とか経済とかの考えを述べていた。それから2年。家のコンピュータ装備は変わり、海に全然行かなくなり、学校は卒業年度。家の状況も変わり、親がガンになったり、ここ1年で手術。今度は転移していたとのことだった。転移性ガンはステージ4。1,2年しかないかもしれない。父も肺炎になって入院したり、こんなにいろんな悪いことが起こるとは。祖母もここ2,3年病院で意識がない状態で入院している。武雄の親族で、まだ健康でいるのは守さん、博子おばさんだけ。田舎の人、自然に囲まれて育った人は強い。
仕事に関してはやり易くなっている。旅するようになった。何より投資知識とスキルが増えた。鎌倉住んで落ち着いたというか精神的に安定して煩悩？迷いとかがなくなったような気がする。
映像を撮りためておくのはいい。当時の考えや表情、心理、方向性、何してたか、日常などいろんなことを振り返ってみて今ある自分と比較してみて、今がどうか考えてみる。Youtubeではなく、考えを述べるのがいい。拝島結構気に入っていたのがわかる。安いし、投資に使ってと言っているがまだ当時は株式投資してないので、学業投資だ。今度は株式投資。お金を投資に集中する生活スタイルにしようとしている。
今度はどのような生活になるのか。前回よりも良くなるように戦略的に考えてみる。心理的に暗くなるのは、旅を加えればどうだろうか。また、車を射程に入れる。というか、ほとんど投資目的の引越しで構わないと思う。投資したいから引っ越すで。

## 機械学習

---

機械学習モデルでのいくつか順序がわかるように記載。
◼️①Get Data-2.ipynb
Yahoofinanceから日付の日の3000社分の画像取得して
「charts_30m_2025-10-28」フォルダなどになる。画像は翌日でも取得可能。
◼️②build_prices_daily.py
build_prices_daily.pyで3000社近くの企業の該当範囲の
株価の終値を取得する。build_prices_daily.pyはsystem_trade-master配下のフォルダ全ての差分を取得して、prices_dailyに反映する。
python build_prices_daily.py \
  --images_root /Users/kensukemachii/Desktop/system_trade-master \
  --start 2025-07-01 \
  --end   2025-10-30 \
  --out_csv /Users/kensukemachii/Desktop/system_trade-master/prices_daily.csv
◼️③label_next_day.pyで、images_dirは、system_trade-masterのことで、その配下のフォルダのファイル名をprices_daily.csvと比較して、終値で5クラスに分類する。
OUT=/Users/kensukemachii/Desktop/labeled_output_5cls_10pct
rm -rf "$OUT"
python /Users/kensukemachii/Desktop/system_trade-master/label_next_day.py \
  --images_dir /Users/kensukemachii/Desktop/system_trade-master \
  --prices_csv /Users/kensukemachii/Desktop/system_trade-master/prices_daily.csv \
  --out_dir "$OUT" \
  --filename_pattern "{ticker}_{date}_30m" \
  --date_fmt "%Y-%m-%d" \
  --scheme five \
  --t_up_small 0.02 --t_up_big 0.10 \
  --t_dn_small -0.02 --t_dn_big -0.10 \
  --symlink \
  --dry_run
◼️python flatten_to_class.py
system_trade-masterに移動して、実行。DOWN,UPフォルダなどの配下の企業名フォルダを抜かして、画像のみにする。
python flatten_to_class.py --root "/Users/kensukemachii/Desktop/SBIPortfolio1119Split/five"
◼️④python3 label_next_day.py
翌日株価で画像をラベリングするUPBIGやDOWNなどラベリングをするスクリプト。「今日のチャート画像 → 翌日が UP_BIG / DOWN_BIG / NEUTRAL か？」を 自動判定してフォルダ分け（ラベリング）します。
python label_next_day.py \
  --images_dir "/Users/kensukemachii/Desktop/system_trade-master/chart" \
  --prices_csv "/Users/kensukemachii/Desktop/system_trade-master/prices_daily.csv" \
  --out_dir "/Users/kensukemachii/Desktop/system_trade-master/labeled_output" \
  --filename_pattern "{ticker}_{date}_30m" \
  --date_fmt "%Y-%m-%d" \
  --scheme five \
  --t_up_small 0.004 --t_up_big 0.07 \
  --t_dn_small -0.004 --t_dn_big -0.07
◼️⑤split_dataset_5cls.py
ラベル済みのフォルダをtrain,valid,testに分ける最終のスクリプト。
◼️⑥evaluate_classwise_accuracy.py
prices_daily.csvで実際の価格変化、redictions_5Classbest_best_baseline.csvの各モデルの各企業に対する予測(UPBIG,UP,DOWN...etc)を突き合わせて、モデルの予測精度を比較する。
◼️⑦evaluate_classwise_accuracy.py
prices_daily.csvで実際の価格変化を見て、予測モデルの各クラスの精度を検証する。
